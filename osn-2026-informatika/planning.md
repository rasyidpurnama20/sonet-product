# Planning Persiapan OSK Informatika 2026

## Gambaran Umum

**Olimpiade Sains Nasional (OSN) – Tingkat Kabupaten/Kota (OSK)**
Bidang: Informatika / Komputer
Waktu pengerjaan: **2,5 jam**, dengan **30–50 soal** yang terbagi dalam 3 bagian.

---

## Struktur Soal

### Bagian A — Abstraksi Berpikir Komputasional
- Soal cerita bergambar yang berkaitan secara tidak langsung dengan konsep informatika.
- Mirip dengan soal-soal **Bebras Indonesia**.
- Melatih kemampuan abstraksi, penalaran logis, dan berpikir algoritmik tanpa kode.

### Bagian B — Pemecahan Masalah Komputasional
- Studi kasus mengarah ke pemrograman kompetitif.
- Setiap 1 deskripsi studi kasus → 3 soal pemahaman.
- Format mirip OSN-P 2025 tingkat nasional, **tanpa perlu membuat program**.
- Semua soal dapat diselesaikan "dihitung di atas kertas".

### Bagian C — Pemahaman Algoritma dalam Bahasa C++
- Diberikan beberapa kode program C++.
- Setiap 1 kode program → 3 soal.
- Dapat diselesaikan dengan cara "dihitung di atas kertas".

> **Tipe soal:** Pilihan ganda, isian singkat, atau benar/salah. Tidak ada soal esai.

## Silabus & Topik Materi

### 1. Matematika Diskrit & Logika
| Topik | Sub-topik |
|---|---|
| Aljabar Boolean | AND, OR, NOT, XOR, penyederhanaan ekspresi, tabel kebenaran |
| Teori Himpunan | Irisan, gabungan, komplemen, diagram Venn, kardinalitas |
| Induksi & Deduksi Logika | Bukti matematika, silogisme, modus ponens/tollens |
| Kombinatorika | Permutasi, kombinasi, prinsip inklusi-eksklusi, pigeonhole principle |
| Deret Aritmetika & Geometri | Rumus suku ke-n, jumlah deret, rekurens |
| Model Matematis | Pemodelan masalah ke persamaan/pertidaksamaan |

### 2. Struktur Data & Algoritma
| Topik | Sub-topik |
|---|---|
| Array | Akses, traversal, pencarian, pengurutan (bubble, selection, insertion) |
| Rekursi | Faktorial, Fibonacci, divide & conquer sederhana |
| Subprogram / Fungsi | Prosedur, parameter, nilai kembalian |
| Percabangan & Perulangan | if/else, switch, for, while, do-while |
| Membaca Algoritma | Trace kode C++, menentukan output program |
| Masukan & Keluaran | Format I/O standar (cin/cout), scanf/printf |

### 3. Graf & Geometri
| Topik | Sub-topik |
|---|---|
| Graf | Graf berarah/tak berarah, adjacency matrix/list, BFS, DFS |
| Pohon (Tree) | Binary tree, traversal (in/pre/post-order) |
| Geometri Komputasional | Koordinat, jarak titik, luas bangun, perpotongan garis |

### 4. Berpikir Komputasional
| Topik | Sub-topik |
|---|---|
| Dekomposisi | Memecah masalah besar menjadi sub-masalah |
| Pengenalan Pola | Mengidentifikasi pola dari serangkaian data |
| Abstraksi | Menyederhanakan masalah ke inti esensialnya |
| Algoritmisasi | Menyusun langkah-langkah penyelesaian masalah |
| Simulasi | Menjalankan proses secara manual step-by-step |
| Optimisasi | Mencari solusi terbaik dari beberapa kemungkinan |
