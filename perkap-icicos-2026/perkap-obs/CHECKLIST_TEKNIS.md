# ✅ Checklist Teknis ICICOS 2026 Streaming

## 📅 1 Minggu Sebelum Event

### Hardware
- [ ] Laptop/PC untuk OBS (min i5, 8GB RAM, dedicated GPU recommended)
- [ ] Backup laptop dengan setup OBS yang sama
- [ ] Camera HD/4K untuk speaker (minimal 2 unit)
- [ ] Microphone wireless/lavalier untuk speaker (minimal 3 set)
- [ ] Audio mixer (optional tapi recommended)
- [ ] Kabel HDMI/USB cadangan
- [ ] Extension cables & power strips
- [ ] Lighting equipment (softbox/ring light)

### Software Setup
- [ ] Install OBS Studio versi terbaru
- [ ] Install Zoom client
- [ ] Install codec pack (K-Lite/VLC)
- [ ] Test semua camera dengan OBS
- [ ] Test audio input/output
- [ ] Import semua 20 frame PNG ke OBS
- [ ] Setup scenes sesuai panduan
- [ ] Export Scene Collection untuk backup

### Konten
- [ ] Video loop Day 1 (format MP4, 1080p)
- [ ] Video transisi (5-10 detik)
- [ ] Video opening Day 1
- [ ] Video half recap Day 1
- [ ] Video recap Day 1
- [ ] Video loop Day 2
- [ ] Video opening Day 2
- [ ] Background music (royalty-free)
- [ ] Logo ICICOS vector/PNG high-res
- [ ] Sponsor logos

### Network & Connectivity
- [ ] Test koneksi internet (min 10 Mbps upload)
- [ ] Backup internet (mobile hotspot/dongle)
- [ ] Zoom meeting link ready
- [ ] Zoom co-host access granted
- [ ] Test Virtual Camera di Zoom

---

## 📅 1 Hari Sebelum Event

### Rehearsal
- [ ] Full rehearsal dengan MC
- [ ] Test transisi antar scenes
- [ ] Test audio levels semua microphone
- [ ] Test camera angles & framing
- [ ] Test presentation window capture
- [ ] Test recording function
- [ ] Briefing dengan tim teknis
- [ ] Assign roles (operator OBS, audio engineer, camera person)

### Final Check
- [ ] Semua file video sudah di local disk (bukan USB)
- [ ] Hotkeys sudah configured
- [ ] Scene transitions smooth (200-300ms fade)
- [ ] Lower thirds / name tags ready (optional)
- [ ] Emergency contact list siap

---

## 📅 Hari H - 2 Jam Sebelum

### Setup Venue
- [ ] Posisi laptop OBS di tempat strategis
- [ ] Setup cameras dengan tripod
- [ ] Setup microphones & test audio
- [ ] Setup lighting
- [ ] Pasang backdrop/banner (jika ada)
- [ ] Cable management rapi & aman

### OBS Pre-Flight Check
- [ ] Open OBS project
- [ ] Load Scene Collection
- [ ] Test semua scenes (1x pass through)
- [ ] Test all audio sources
- [ ] Test all camera feeds
- [ ] Set recording destination folder
- [ ] Clear disk space (min 50GB free)
- [ ] Disable system notifications
- [ ] Disable auto-updates
- [ ] Close unnecessary applications
- [ ] Set power plan ke "High Performance"

### Zoom Setup
- [ ] Join Zoom meeting sebagai co-host
- [ ] Mute all participants saat join
- [ ] Disable waiting room (atau assign someone)
- [ ] Test share screen (jika perlu)
- [ ] Start Virtual Camera dari OBS
- [ ] Select "OBS Virtual Camera" di Zoom video settings
- [ ] Test audio di Zoom
- [ ] Enable "Original Sound" di Zoom audio settings

---

## 📅 Saat Event Berlangsung

### Operator OBS Checklist
- [ ] Monitor audio levels (tidak red/clipping)
- [ ] Monitor scene preview sebelum switch
- [ ] Smooth transition dengan fade
- [ ] Watch out untuk window minimize (presentation capture)
- [ ] Monitor chat Zoom untuk technical issues
- [ ] Keep eye on recording indicator
- [ ] Monitor disk space

### Emergency Protocols
- [ ] Jika OBS crash → switch ke backup laptop
- [ ] Jika internet drop → switch ke backup connection
- [ ] Jika camera fail → switch ke backup camera atau phone
- [ ] Jika audio fail → gunakan Zoom audio langsung
- [ ] Jika presentasi tidak capture → screen share Zoom

### Recording
- [ ] Start recording saat opening dimulai
- [ ] Pause saat break panjang (optional)
- [ ] Stop recording saat closing selesai
- [ ] Backup file segera ke cloud/external drive

---

## 📅 Setelah Event

### Post-Production
- [ ] Stop all recording & virtual camera
- [ ] Save recording files
- [ ] Upload recording ke cloud storage
- [ ] Backup Scene Collection & project files
- [ ] Export logs jika ada issues

### Evaluasi
- [ ] Review recording quality
- [ ] Note technical issues yang terjadi
- [ ] Feedback dari tim
- [ ] Improvement untuk next event

## 💡 Pro Tips

1. **Always test before go live** - Jangan skip rehearsal
2. **Monitor preview** - Selalu cek preview sebelum switch scene
3. **Audio is king** - Audio jelek lebih fatal daripada video jelek
4. **Have backup** - Backup everything: laptop, camera, internet, audio
5. **Stay calm** - Jika ada masalah, tetap tenang dan switch ke backup plan
6. **Communication** - Tim harus punya channel komunikasi (WhatsApp group)
7. **Document issues** - Catat semua masalah untuk improvement
8. **Hydrate & breaks** - Operator juga butuh istirahat!
