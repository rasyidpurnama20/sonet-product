# Comprehensive DL-EEW Review Article (Single-Station vs Multi-Station)

A 1084-line LaTeX review article targeting Earth-Science Reviews, covering deep learning approaches to earthquake early warning with an explicit single-station vs multi-station comparative framing. The article spans 10 sections from physical fundamentals through future directions, citing 96 of 156 provided bibliography entries, and compiles to a 41-page PDF. The writing is technically dense and well-structured for a survey paper, but several bibliographic integrity issues, a formula error, and repository hygiene gaps need attention before submission.

**Watch for:** Mismatched citation key years and metadata (confirmed), an incorrectly rendered tau_c formula that produces a trivially wrong expression (confirmed), 60 uncited bibliography entries inflating the .bib file (confirmed), and LaTeX build artifacts tracked or unignored in the repository (confirmed).

## High-level view

The bibliography contains real, verifiable references to established work (PhaseNet, EQTransformer, GENIE, STEAD, SeisBench), but several entries have inconsistent metadata: citation keys encode one year while the year field contains another, author attribution is wrong for at least one key, and 10 entries trigger BibTeX warnings for missing fields. These are the kind of errors that break trust with reviewers who spot-check references.

The tau_c formula in Section 2.2 is mathematically incorrect as written: the numerator and denominator contain expressions that simplify such that the formula produces a dimensionally wrong result (frequency squared, not period). The standard Kanamori (2005) definition uses a simpler ratio.

Repository hygiene is poor: LaTeX compilation artifacts exist as untracked files without .gitignore coverage, and the .bbl file (a generated artifact) is committed to version control. The accuracy-latency figure in Section 6 plots synthetic coordinate data (smooth curves with round numbers) rather than actual published results, which should be explicitly labeled as schematic to avoid misrepresentation.

## Bibliographic integrity

The `hoshiba2011earthquake` key contains `year = {2008}` in the .bib file. The text uses this citation twice: once for JMA system operation and once for a "2013 false alert" incident in Tokyo. A 2008 paper cannot document a 2013 event. Either a different Hoshiba paper (post-2013) is intended, or the claim about the 2013 incident needs a different citation entirely.

The `brown2017elarms` key is more severely broken: the author field is "Chung, Angela I." and the year is 2020, describing the 2019 Ridgecrest sequence. The key name suggests Brown et al. 2017 on ElarmS, which is an entirely different paper about an entirely different system evaluation. A reviewer who follows this citation will find a complete mismatch between the in-text claim and the referenced work.

The `mcmahon2017federated` key misspells McMahan (the Google Federated Learning author). The entry type is `@article` but lists a `booktitle` field (AISTATS) with no `journal` field—semantically wrong and producing a BibTeX warning. Should be `@inproceedings`.

## The tau_c formula error

In Section 2.2 (Eq. 3), the formula for predominant period is:

```latex
\tau_c = 2\pi \frac{\sqrt{\frac{\int_0^{\tau_0} \dot{u}^2(t) dt}{\int_0^{\tau_0} u^2(t) dt}}}
              {\sqrt{\frac{\int_0^{\tau_0} u^2(t) dt}{\int_0^{\tau_0} \dot{u}^2(t) dt}}}
```

Let A = integral of u_dot^2, B = integral of u^2. The expression becomes:

`2*pi * sqrt(A/B) / sqrt(B/A) = 2*pi * sqrt(A/B) * sqrt(A/B) = 2*pi * (A/B)`

This is dimensionally [1/time^2] * [time] = [1/time]—a frequency, not a period. The standard Wu & Kanamori (2005) definition is `tau_c = 2*pi * sqrt(B/A)`, which has dimensions of time and represents the predominant period of the initial P-wave. The garbled version in the manuscript likely results from an attempt to show derivation steps that collapsed incorrectly.

## Schematic figures without labeling

The accuracy-latency pgfplots figure (Figure 3) uses hand-crafted coordinate pairs with suspiciously round values:

```
(1, 0.45) (2, 0.55) (3, 0.65) (4, 0.70) ...
```

These are not extracted from any cited study. For a review journal, this is acceptable as a conceptual illustration but must be explicitly captioned as "schematic" or "illustrative"—the current caption says "Schematic representation" which is borderline adequate but could be strengthened to avoid any suggestion that these curves represent aggregated empirical data.

## Repository hygiene

The diff commits `main.bbl` (889 lines), which is regenerated from references.bib on every BibTeX run. This guarantees merge conflicts if multiple people edit the bibliography. The `.gitignore` should include:

```
*.aux *.bbl *.blg *.log *.out *.spl *.synctex.gz *.fls *.fdb_latexmk
```

The committed PDF is a judgment call (useful for collaborators without LaTeX), but should be generated via CI or a Makefile rather than committed from local builds where compilation environment varies.
